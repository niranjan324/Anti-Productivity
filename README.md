### Team Name: Anti-Productivity Syndicate

### Project Description
A ruthless, adversarial Chrome Extension (Manifest V3) that auto-intercepts unprotected browser tabs and holds them hostage in an unescapable cyberpunk lockdown window—forcing users to solve increasingly sadistic mental arithmetic under high-pressure time decay, or face immediate zero-redemption tab liquidation, Russian Tab Roulette, and eternal public shaming in the Tab Graveyard.

### The Problem (that doesn't exist)
Modern humans possess infinite willpower and never open 47 tabs of YouTube, Reddit, or Wikipedia at 3:00 AM while pretending to study. Friendly reminder extensions and gentle mindfulness bells are far too effective, so we needed an unhinged digital executioner that replaces self-discipline with raw algorithmic terror and psychological warfare.

### The Solution (that nobody asked for)
Instead of softly suggesting you focus, this extension launches a pinned, focus-trapping interceptor window every time you visit an unprotected webpage. If you fail to solve procedural math equations (from 2-digit sums to 2x2 matrix determinants and camouflaged phantom numbers), the 7-second acoustic harassment siren blares, the Russian Tab Roulette cycles across all your open tabs, and your innocent tabs are summarily vaporized into the persistent Tab Graveyard & Cognitive Debt Registry with a scathing obituary.

### Technologies/Components Used
For Software:

- **Tools:** Git, Chrome DevTools, Node.js runtime validation

---

### Key System Architecture & Core Modules
1. **Auto-Interception Engine (`background.js`):** Automatically listens to navigation (`chrome.tabs.onUpdated`) and tab switching (`chrome.tabs.onActivated`) on unprotected schemes (`http:`, `https:`) and spawns dedicated interceptor windows.
2. **Focus Trap & Defiance Engine (`background.js`):** Aggressive window blur monitoring and defiance fallback—closing or escaping the window immediately executes the target tab as a defiance penalty.
3. **5-Tier Adaptive Math Engine (`math-engine.js`):** Procedural equation generator scaling from basic arithmetic to modulo calculus, quadratic roots, 2x2 matrix determinants, and stochastic (10%) Camouflage Phantom Operators.
4. **Russian Tab Roulette Engine (`tab-roulette.js`):** Decelerating slot-machine visual cycle with mechanical audio clicks and Text-to-Speech (TTS) synthesized execution orders.
5. **Tab Graveyard & Cognitive Debt Registry (`graveyard.html` / `graveyard.js`):** Morbid obituary dashboard tracking fallen tabs, lethal equations, cognitive debt metrics, and filterable death logs.

### Implementation

# Installation
1. Clone this repository or download the source code:
   ```bash
   git clone https://github.com/niranjan324/Anti-Productivity.git
   ```
2. Open Google Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** in the top right corner.
4. Click **Load unpacked** and select the cloned project directory (`Anti-Productivity`).

# Run
1. Navigate to any regular website (e.g. `https://youtube.com`, `https://reddit.com`, `https://github.com`).
2. The **Anti-Procrastination Tab Executioner** will automatically intercept your browsing with the unescapable HUD panel.
3. Solve the equations before the timer hits `0s`, or watch the Tab Roulette claim your tabs!
4. Click **TAB GRAVEYARD** to inspect the obituaries of liquidated tabs and your cognitive debt.
